# --- subprocess with config-derived argv (semgrep) --------------------------
# All three are list-form subprocess.run with no shell=True, so there is no
# shell-injection surface. The argv elements come from constants, from
# sys.executable, or from this project's own config - not from the network.
# The residual is PATH resolution of `claude` (shutil.which), which requires an
# attacker who can already write to the user's PATH, i.e. who already has
# execution as that user.
semgrep  Templates/Scripts/graph_calendar_fetch.py  dangerous-subprocess-use-tainted-env-args   # list form, argv from constants + config. re-check 2026-11-25
semgrep  Templates/Scripts/meeting_pull.py          dangerous-subprocess-use-tainted-env-args   # list form; `claude` via shutil.which, user's own PATH. re-check 2026-11-25
semgrep  Templates/Scripts/morning_dashboard.py     dangerous-subprocess-use-tainted-env-args   # list form; LAUNCHCTL_BIN defaults to /bin/launchctl, env override is a test seam. re-check 2026-11-25

# --- XML parsed with ElementTree (bandit B314 / semgrep use-defused-xml) -----
# ACCEPTED, NOT DISMISSED. These are real: xml.etree.ElementTree is documented
# as not secure against maliciously constructed data (entity expansion /
# quadratic blowup). The fix is defusedxml, which is already present in the
# resolved dependency tree transitively but is NOT declared in
# requirements.txt - declaring a new dependency on a cross-platform template is
# a deliberate change, not a drive-by. Tracked as an open finding for CISO
# packet v2.3 rather than silently closed.
#   podcast_transcribe.py parses a podcast RSS feed, which is genuinely
#   untrusted external input. This is the one that matters.
#   handoff_blob_pull.py parses an Azure Blob listing; the Blob relay was
#   dropped 2026-08-13 and survives as an optional secondary path.
bandit   Templates/Scripts/podcast_transcribe.py    B314   # OPEN FINDING: untrusted RSS via ElementTree. Fix = declare defusedxml. re-check 2026-09-25
bandit   Templates/Scripts/handoff_blob_pull.py     B314   # OPEN FINDING: Azure listing via ElementTree; relay is dropped/optional. re-check 2026-09-25
semgrep  Templates/Scripts/podcast_transcribe.py    use-defused-xml   # as above. re-check 2026-09-25
semgrep  Templates/Scripts/handoff_blob_pull.py     use-defused-xml   # as above. re-check 2026-09-25
