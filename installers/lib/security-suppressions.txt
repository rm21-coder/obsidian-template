#   <tool>  <path>  <rule>  count=<N>   # why this is accepted ... re-check YYYY-MM-DD

# A finding here does not fail the suite. Everything else does. The point of a
# file rather than an inline comment is that an accepted risk stays reviewable

# every finding of its rule in its file, not just the ones argued:
#   - count=<N> is the exact number of findings the line covers. One more fails
#     the run (a new site appeared); one fewer fails it too (the line no longer
#     describes the code). Name the lines in the rationale.
#   - a re-check date that has passed FAILS the run; within 14 days it is a
#     NOTE. A missing date, count or rationale fails.
